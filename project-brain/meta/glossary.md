# Glossary

- **MS-n**: milestone. MS-1 landing and menu; MS-2 staff dashboard; MS-3 takeaway PWA.
- **WP-n**: work package. WP-1 backend auth; WP-2 auth view page; WP-3 secure environment.
- **WP-n.m**: task inside a work package.
- **DEP-n**: dependency between work packages.
- **D-n**: logged decision, with evidence.
- **ISS-n**: open issue or unknown needing a human answer.
- **RK-n**: risk.
- **CR-n**: change record against a baseline field (needs gate G2).
- **CORRECTION**: append-only fix to an earlier record, citing its original ID.
- **Baseline**: approved dates, scope and effort (gate G1). None issued yet.
- **Forecast**: a dated estimate, not approved.
- **GREEN / AMBER / RED / UNKNOWN**: status per R14. UNKNOWN when no dated, tagged forecast exists or no baseline to compare.
- **Invitation link**: the only way new staff reach login. Valid 7 days (D-2).
- **Owner account**: pre-seeded in the database (D-1).
- **DBA**: database administrator. Name unknown (ISS-5).
- **DN1 / DN2 / DN6**: PM does-not-own rules: technical design (tech lead), other roles' effort, legal and security sign-off (named reviewer).
